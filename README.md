# SamirNet Videos

تطبيق Android مبني بـ Flutter/Dart وواجهة عربية RTL. يوفر إدارة روابط الوسائط، بحث YouTube رسمي، وعرض بيانات الفيديو المتاحة من YouTube Data API.

## الوظائف الموجودة

- واجهة عربية RTL، الوضع الفاتح/الداكن، وشريط تنقل.
- حفظ روابط الوسائط في SQLite.
- التعرّف على روابط YouTube وTikTok وInstagram وSnapchat وFacebook.
- تنزيل الفيديوهات العامة المدعومة على الجهاز عبر yt-dlp، مع جلب الصيغ الفعلية، اختيار الدقة، وتنزيل الصوت فقط أو الفيديو.
- تشغيل فيديو YouTube داخل التطبيق عبر المشغّل الرسمي المضمّن، وعرض بياناته ونتائج مشابهة عند توافر البحث.
- بحث YouTube عبر YouTube Data API v3، عند إدخال مفتاح API صالح من الإعدادات.
- جلب بيانات الفيديو العامة من API: العنوان، القناة، الوصف، تاريخ النشر، المدة، الدقة الأصلية، والمشاهدات والإعجابات والتعليقات عندما تكون متاحة.
- GitHub Actions للتحليل والاختبارات وبناء APK.

## تشغيل المشروع

يتطلب Flutter SDK وAndroid SDK:

```bash
flutter create --platforms=android --project-name samirnet_videos .
flutter pub get
flutter analyze
flutter test
flutter run
```

لبناء APK:

```bash
flutter build apk --release
```

في GitHub افتح **Actions → Flutter Android build** لتنزيل ملف APK من Artifacts بعد نجاح جميع خطوات البناء.

## إعداد بحث YouTube

1. أنشئ مشروعًا في Google Cloud Console.
2. فعّل YouTube Data API v3 وأنشئ API key.
3. افتح إعدادات التطبيق وأدخل المفتاح. لا تضع مفاتيح خاصة أو كلمات مرور في المستودع.

بيانات YouTube تأتي من API الرسمي؛ عدد الإعجابات أو التعليقات قد لا يكون متاحًا لبعض الفيديوهات أو إعدادات API.

## حدود مهمة

- يتطلب البحث الرسمي في YouTube مفتاح YouTube Data API محفوظًا في إعدادات التطبيق. محرك yt-dlp مخصص لتحليل الروابط العامة وتنزيل الصيغ المتاحة.
- حجم APK سيزداد لأن محرك yt-dlp وFFmpeg يُضمّنان داخل التطبيق. قد تتعذر بعض الروابط بسبب تغييرات المنصة أو قيود الشبكة أو تسجيل الدخول.
- لا يحاول التطبيق تجاوز DRM أو الوصول إلى فيديوهات خاصة أو محمية.

## ما الذي لا يمكن اعتباره مكتملًا بعد

- اختيار جودة تنزيل فعلية يحتاج إلى قائمة صيغ/روابط وسائط يوفّرها مصدر تنزيل متوافق. لا يمكن استنتاج صيغ 360p/720p/1080p من رابط صفحة الفيديو أو من YouTube Data API وحده.
- تنزيل ملف من صفحة YouTube/TikTok/Instagram/Facebook يتطلب موفّرًا مخوّلًا ومتوافقًا مع شروط المنصة. النسخة الحالية لا تستخرج روابط البث المخفية ولا تتجاوز DRM أو تسجيل الدخول أو قيود الوصول.
- رابط مباشر واحد ينزّل الملف كما يقدّمه الخادم؛ لا يمكن تغيير جودته من داخل التطبيق إذا لم يوفّر الخادم نسخًا متعددة.
- يلزم التحقق من نجاح أحدث GitHub Actions واختبار APK على جهاز Android قبل اعتبار الإصدار جاهزًا للنشر.

لا يدّعي التطبيق نجاح تنزيل لم يحدث، ولا يجمع كلمات مرور المنصات.
