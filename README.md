# SamirNet Videos

تطبيق Android باستخدام Flutter وDart لإدارة روابط الوسائط والتنزيلات المحلية.

## الحالة الحالية

المستودع بدأ بهيكل المشروع الأساسي. الواجهات وإدارة الإعدادات والسجل المحلي يمكن تشغيلها دون خادم. تحليل منصات التواصل والبحث عن YouTube والتنزيل من هذه المنصات يحتاج إلى موفّر متوافق وموثق؛ لا يدّعي التطبيق دعم تنزيل محتوى غير متاح فعليًا.

## التشغيل

```bash
flutter pub get
flutter analyze
flutter test
flutter run
```

لإنشاء APK:

```bash
flutter build apk --release
```

## ملاحظات

- لا توجد مفاتيح API سرية ضمن التطبيق.
- روابط المحتوى الخاص أو المحمي لا يتم تجاوزها.
- لا تعتبر ميزة تنزيل منصة مدعومة حتى يضاف موفّر متوافق ويُختبر على جهاز حقيقي.
