# SamirNet Videos

تطبيق Android باستخدام Flutter وDart، بواجهة عربية RTL وهوية مرئية حمراء/صفراء، مع الوضع الفاتح والداكن وسجل محلي لروابط الوسائط.

## ما هو موجود حاليًا

- واجهة رئيسية عربية مع شريط تنقل سفلي.
- شاشة إرسال رابط مع لصق من الحافظة والتحقق من روابط HTTP/HTTPS والتعرف على نطاقات YouTube وTikTok وInstagram وSnapchat وFacebook.
- شاشة بحث توضح أن البحث الفعلي يحتاج إلى موفّر رسمي أو API.
- سجل محلي باستخدام SQLite، وإعداد محفوظ للوضع الفاتح/الداكن/حسب النظام.
- اختبار وحدة للتحقق من الروابط والتعرف على المنصات.
- GitHub Actions لتشغيل التحليل والاختبارات وبناء APK، مع توليد مجلد Android في بيئة CI.

## تشغيل محلي

يتطلب Flutter SDK وAndroid SDK. لأن ملفات منصة Android لم تُضمّن بعد في المستودع، أنشئها مرة واحدة:

```bash
flutter create --platforms=android --project-name samirnet_videos .
flutter pub get
flutter analyze
flutter test
flutter run
```

لبناء APK:

```bash
flutter build apk --release
```

في GitHub افتح تبويب **Actions** ثم سير العمل **Flutter Android build** لتنزيل APK من **Artifacts** بعد نجاح جميع الخطوات.

## حدود واضحة

- لا يعمل تنزيل الفيديو من YouTube أو TikTok أو Instagram أو Snapchat أو Facebook في النسخة الحالية؛ التعرف على النطاق لا يعني توفر ملف للتنزيل.
- لا يوجد بحث YouTube حي أو تحليل بيانات فيديو أو اختيار جودة في هذه المرحلة.
- السجل المحلي يحفظ روابط وحالات أولية فقط، ولا يثبت أن ملفًا قد نُزّل.
- يلزم إضافة موفّر بحث/تحليل وتنزيل متوافق مع شروط المصدر، ثم اختباره على جهاز Android فعلي قبل إعلان دعم هذه الوظائف.
- لا تُجمع كلمات مرور، ولا تُتجاوز حماية المحتوى الخاص، ولا توجد مفاتيح API سرية في المستودع.
